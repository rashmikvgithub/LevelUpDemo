Core Modules
============

1. My Daily Activities

Purpose:
Allow user to track activities performed during the day.

Activity:
- Add Activity
- Edit Activity
- Delete Activity
- View Daily Activities
- Search Activities
- Filter by Date added/retired

Daily Activity Evaluations/Grades
For each activity, you can grade yourself daily.
examples: "exercise", "read 10 pages of a book", "eat well", "enter time in timesheet"
Fields:
- Activity Id
- Title
- Description
- Evaluation Date
- Score (0 through 5 (integer) (0 means skip/fail))
- Notes (optional)


2. Goals (Other Menu)

Purpose:
Manage future personal and professional long-term goals (these won't be graded, you can just click on a goal and enter an update, including "note", and "% complete", and this will be logged).
examples: "lose 10 lbs", "get ai certification", "2 family vacations this year", "learn python"
Features:
- Create Goal
- Edit Goal
- Delete Goal
- Mark Completed
- Track Progress (each progress checkpoint will have it's own row in a table)

Goal Fields:
- Goal Id
- Title
- Description
- Target Date
- Progress Percentage (could be pulled from latest progress tracking/checkpoint entry)
- Status
  - Not Started (0%)
  - In Progress (1-99%)
  - Completed (may be able to be derived from progress tracking/checkpoint table 100%)

Dashboard
=========

Provide a dashboard showing:

- Today's Score
- Weekly Score
- Monthly Score
- Active Goals
- Goal Completion Count
- progress tracking/checkpoint Trend Chart

Recommendation Engine
========================

In the same place where you grade/evaluate yourself on your daily activities:
Have a "help me" or "ideas?" button, that will show a random suggestion on how to do better at completing your daily activities:
some hard-coded (stored in db) recommendations such as:
- Reschedule activity to a better time
- Break activity into smaller tasks
- Set reminders
- Reduce task complexity
- Improve consistency

note:
potential future-scope:
replace random hard-coded suggestions with ai/llm generated suggestions (keep UI same)
If an activity repeatedly receives low scores or is skipped multiple times, show a pop-up asking if they want help or a suggestion/idea on how to do better

Store recommendation history.
